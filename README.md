# Portfolio — Saliou Diop

Portfolio personnel construit avec React + Vite.

## Installation

npm install

## Lancer en développement

npm run dev

Puis ouvrir l'URL affichée (par défaut http://localhost:5173).

## Construire pour la production

npm run build

Les fichiers statiques sont générés dans le dossier dist/, prêt à être déployé (Netlify, Vercel, etc.).

## À personnaliser

- Dans src/App.jsx, remplacer les liens "Rapport" et "GitHub" des projets (actuellement en href="#") par les vraies URLs.
- Remplacer le lien "Télécharger le CV" (actuellement en href="#") par le lien vers le PDF du CV hébergé.
